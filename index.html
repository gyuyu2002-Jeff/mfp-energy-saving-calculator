03 · TEC 測試方法與能源效率基準

TEC 測試程序與能源效率基準：事物機如何取得「節能標章」？

經濟部能源署與國際能源之星（ENERGY STAR）以標準化 168 小時週期測試 TEC，並依「列印速度」制定階梯式能源效率基準限值。實測值不僅要低於基準線，更需比能源之星加嚴 20%~25%（市場前 15%~20% 頂尖機種），才能榮獲國家級「節能標章」。

① 什麼是 168 小時 TEC 測試？

模擬一般辦公室標準週期：5 天上班工作日 + 2 天週末睡眠。量測首件喚醒加熱、分批列印作業、收尾待機至睡眠的每階段能耗，得出每週典型用電度數（kWh/週）。

② 什麼是「能源效率基準」？

官方非設定單一固定門檻，而是依列印速度（ipm）及彩色/黑白訂出動態容許上限公式（TECcriteria）。速度越快雖能耗上限略高，但單位張數效率要求更為嚴苛。

③ 如何取得「節能標章」？

符合能源之星代表市場前 25%；而台灣節能標章要求更加嚴格 25%（實測值 ≤ 75% × 基準線），只有前 15%~20% 頂尖省電機種才能獲證，並取得政府機關綠色採購優勢。

資料來源與假設

  • TEC 測試程序：經濟部能源署・能源之星合格影像設備之典型用電量測試程序（TEC）
  • 耗電換算與業界實務：互盛官方專題・影印機耗電多少？TEC 怎麼看（辦公室節能省電全攻略）↗（年用電度數估算 ≈ TEC × 52 週 × 台數；年電費 ≈ 年用電 × 每度電價）
  • 機型 TEC 數據：
    • 美國能源之星官方資料庫：ENERGY STAR Certified Imaging Equipment（SODA API 資料集 t2v6-g4nf），欄位 typical_electricity_consumption_tec_kwh_wk。
    • 品牌台灣官網規格書撈取：針對能源之星全球 API 尚未及時收錄之熱銷機種（如 Epson EM-C8101、EM-C8100、WF-C878R），直接由 Epson 台灣原廠型錄技術手冊撈取實測數據（標記為「🏢 官網規格」）。
  • 電力排碳係數：經濟部能源署公告 113 年度 0.474 kg CO₂e/度（可在第 01 頁參數調校盤調整為最新公告值）。

  • TEC 是標準化測試值，實際用電會因印量、睡眠設定、使用習慣而不同。適合用來做機型間的比較與預估。
